# Thapar Share & Find

Lost & Found Board (Front-End Prototype)
Lost items rarely find their owners. Build a card-based listing page for Thapar Institute of Engineering & Technology where users post items (with image preview via FileReader), search, filter by category/location, and mark items as “claimed.” Also provide option for other students who are in need of some essential items, then they can check if it is available or not and should be costed as low as possible. You can also state in this project the benefits of this, cost reduction, finding important student items which would otherwise be lost.
